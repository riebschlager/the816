# the816.com UI kit

Click-through recreation of Chris Riebschlager's portfolio (https://the816.com, Astro) restyled in this system.

- `index.html` — app shell (SiteHeader + screen + SiteFooter). Current page persists in localStorage.
- `screens.jsx` — HomeScreen, ProjectsScreen, ProjectDetailScreen (Thundergong), BlogScreen, PostScreen (Milhouse), AboutScreen.

Click path: Home → "See the projects" → Thundergong → "All projects"; Blog → "Make Milhouse Gorgeous…"; About.

Copy is verbatim from the live site (lightly trimmed). All photos are local copies in `assets/images/` (from the816 repo and user uploads). "Interactive Audio in TouchDesigner" has no hero on the live site, so it shows its alt text in an empty frame.
